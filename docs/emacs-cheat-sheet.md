# Emacs Cheat Sheet

This is a cheat sheet for Emacs commands.

## Basic Commands

* `C-x C-f` - Find file
* `C-x C-s` - Save file
* `C-x C-w` - Save as
* `C-x C-c` - Quit Emacs

## Navigation

* `C-p` - Previous line
* `C-n` - Next line
* `C-b` - Backward char
* `C-f` - Forward char
* `C-a` - Beginning of line
* `C-e` - End of line
* `M-f` - Forward word
* `M-b` - Backward word
* `M-v` - Page up
* `C-v` - Page down
* `M-<` - Beginning of buffer
* `M->` - End of buffer

## Editing

* `C-d` - Delete char
* `M-d` - Delete word
* `C-k` - Kill line
* `C-w` - Kill region
* `M-w` - Copy region
* `C-y` - Yank
* `C-/` - Undo

## Search and Replace

* `C-s` - Search forward
* `C-r` - Search backward
* `M-%` - Query replace

## Buffers and Windows

* `C-x b` - Switch buffer
* `C-x k` - Kill buffer
* `C-x 0` - Delete window
* `C-x 1` - Delete other windows
* `C-x 2` - Split window vertically
* `C-x 3` - Split window horizontally
